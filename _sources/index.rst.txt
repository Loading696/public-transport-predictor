Модули и границы
================

**ML-ядро** (``src.predictor``, ``src.patterns``) строит признаки и обучает модель.
Артефакты передаются в Backend файлами ``ml/model.cbm`` и ``ml/features.json`` —
между модулями нет импортов, поэтому ML-ядро переобучается независимо.

**Backend** (``backend.main``, ``src.runtime``, ``src.ndtp*``, ``src.cascade``,
``src.batching``) принимает поток телеметрии, выполняет инференс и отдает снимок
витрины для дашборда.

Причинность и анти-утечка
==========================

Признаки для точки прогноза ``T`` строятся только по телеметрии с
``event_time <= T``: срез выполняется поиском
``np.searchsorted(times, T, side="right")`` отдельно для каждой точки.
Фактическое время прибытия ``time_fact_begin`` не читается ни одним модулем.
